# rewrite-agent で文章を書き直す

`rewrite-agent` は、渡された文章を読みやすくリライトする CLI ツールです。このプラグインが有効な環境では Bash ツールの PATH に登録されているため、コマンド名だけで実行できます。Command Code の Provider API を使用しており、API キーは環境変数 `CMD_API_KEY`、または `~/.commandcode/auth.json` から自動で読み込まれます。なお、長文の処理には 20 秒程度かかります。

## 最終回答

各ターンの最後にユーザーへ返す「最終回答」は、言語や文章の長さを問わず、常に rewrite-agent で書き直した本文を出力します。ツール呼び出しの合間に返す途中経過の発話は書き直しの対象外です。

- 1 行目に `<!--final-->` だけを記述し、2 行目以降に本文を続けてください。heredoc で rewrite-agent を呼び出さないでください。
- プラグインのフックがこの目印を検知し、発話が保存される直前に本文を自動で書き直します。画面表示、transcript、Claude 自身のコンテキストのすべてが書き直し後の本文に置き換わります。
- 書き直しが完了するまでの十数秒間は、先頭に `[rewriting]` が付いた原文が表示されます。
- `claude -p` の実行時は書き直さず、目印を削除するのみです。また、サブエージェントの発話も書き直しません。
- 途中経過の発話には目印を付けないでください。

## ファイルに残す文章

ファイルへ書き込む文章は、対象の種類を問わず、書き込む前に以下の手順で書き直します。Markdown 文書、README、ノートのほか、SKILL.md、AGENTS.md、CLAUDE.md、memory などのエージェント向け指示ファイル、コード内のコメントや docstring もすべて対象です。

1. Write や Edit を使って、ファイル内に下書きを作成します。
2. 作成・変更した部分のみを heredoc で `rewrite-agent --replace-in 対象ファイル` に渡します。ツールがファイル内の該当箇所を特定し、書き直した文章へ直接置き換えます。
   - 新規ファイル全体を書き直す場合は、`rewrite-agent --replace-in 対象ファイル < 対象ファイル` でファイル全体を渡します。
   - 既存ファイルでは、文書全体を一度に渡さないでください。変更していない段落まで意図せず書き換わり、差分が追えなくなります。
   - コードのコメントや docstring を書き直す場合は、該当する文章のみを渡します。

   ```bash
   rewrite-agent --replace-in 対象ファイル <<'REWRITE_EOF'
   （手順 1 で書いた部分）
   REWRITE_EOF
   ```

3. 書き直された本文を自分で打ち直さないでください。コマンドが exit 0 で終了していれば、ファイルの書き換えは完了しています。exit 1 で終了した場合はファイルは変更されず、下書きのまま残ります。渡した文章がファイル内に「ちょうど 1 箇所のみ」存在しないと置換に失敗するため、エラーが出た場合は前後の文脈を含めて記述が一意に特定できる範囲を指定し直してください。
4. 置換完了後、同じファイルを続けて Edit する場合は、事前にファイルを Read し直してください。

`rewrite-agent <<'REWRITE_EOF' > 対象ファイル` のように、シェルリダイレクトを使って書き込まないでください。コマンドが exit 1 で失敗した際に、既存ファイルの内容が空になってしまいます。
